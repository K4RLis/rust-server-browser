# 🦀 Rust Server Browser

Поиск серверов игры **Rust** с кучей фильтров и живым онлайном.
Данные берутся в реальном времени из публичного API [BattleMetrics](https://www.battlemetrics.com/).

## ✨ Возможности
- 🔍 **Сканер всех серверов** — фоновая дозагрузка всей базы (с учётом лимитов API).
- 📊 **Реальный онлайн** — живая сумма игроков по всем серверам.
- 🗺️ **Карта мира второй фоткой** к каждому серверу (из RustMaps).
- 🎛️ **Фильтры:** регион/страна, тип (Official/Community/Modded/Vanilla),
  скорость фарма (1x/2x/3x/5x/10x+/100x+), размер и тип карты, онлайн,
  свежий вайп, переработчик на рыбачке и др.
- ▶️ Кнопка подключения (`steam://`) и копирование `connect ip:port`.

## 🚀 Как открыть
Просто открой `index.html` в браузере — это обычный сайт, без установки.
